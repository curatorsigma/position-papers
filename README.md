# Jonathan Schleucher - Personal position papers

This repository contains papers stating and explaining my personal convictions on some topics, mostly theological.
This repository is CC0 - feel free to use the templates, or any part of my argumentation however you want. If you want to engage with or cite my views, please make sure to include the exact version of the github repository at time of citation; since none of these papers are ever guaranteed to be stable, pinning a specific version is very important to remove unnecessary misunderstandings down the line.

If you disagree (with substantive arguments) with any of my points, feel free to reach out in writte form.
